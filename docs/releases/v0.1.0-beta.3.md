# Last Blade 2 Frame Lab v0.1.0-beta.3

A more compact layout for comparing saved Last Blade 2 move measurements across
Power, Speed and EX. This release updates the viewer UI; it does not add new
frame-data measurements or change the game.

## Changes since beta.2

- **Character dropdown in the upper-right corner** replaces the roster sidebar,
  leaving more room for a wider move list.
- **Character overview** shows per-mode measured damage-taken scales and stun
  capacities, alongside available ROM attack-scale references. Unverified maximum
  HP and missing values remain blank.
- **All-mode frame table** shows Power / Speed / EX together, with separate
  Hit / Block / Whiff rows for startup, active frames, recovery, damage, stun,
  meter and advantage. Held, released and switched guard remain distinct.
- **Recording controls move beside playback.** Click a table row or choose its
  sword mode and outcome to view the matching clip and timeline. Detailed
  selected-recording statistics, variants and research panels remain available.
- **The move list spans all three modes**, so choosing a playback mode does not
  hide moves that only have evidence in another mode.
- **Character portraits** appear beside the selector and character name when
  supplied by the selected data pack. Individual images and roster-sheet regions
  are supported, with labelled placeholders for missing or broken images.
- Wiki disagreements retain their red highlights and source/comparison tooltips.
  Missing contexts do not borrow measurements or clips from another outcome or
  mode. Throw-whiff duration and weapon rebound retain separate labels.

## Data and compatibility

The application ZIPs contain the procedural demo only. **Real recordings, game
portraits, ROMs, BIOS and emulator binaries are not bundled.** Open your existing
pack with **Choose Data Folder**. Older packs still work; packs without portrait
metadata show placeholders. To use the new local portraits, select the updated
data pack separately. The local portrait set covers 18 roster characters;
Hagure and Kotetsu currently use placeholders.

The comparison table uses representative primary recordings or separately
labelled RAM trials. Selected variants may differ; consult their detailed
statistics. These are setup-dependent observations, not universal constants or
proof of complete move coverage. No outstanding research gap is reclassified as
verified by this release.

## Downloads

- **macOS:** `LastBlade2-FrameLab-v0.1.0-beta.3-macOS-universal.zip` — Apple Silicon
  and Intel, macOS 12+. Extract and open **Last Blade 2 Frame Lab.app**.
- **Windows:** `LastBlade2-FrameLab-v0.1.0-beta.3-Windows-x64.zip` — Windows 10/11
  x64 with Microsoft Edge WebView2 Runtime. Extract the entire ZIP; keep the EXE,
  loader DLL and `web/` folder together.

No Node.js, Python or emulator is required to run the packaged viewer.
`SHA256SUMS.txt` and `release-manifest.json` identify the application archives.

## Validation and platform limits

- 53 source tests pass, including mode/outcome isolation and guard-policy tests.
  TypeScript and production builds pass.
- Browser checks cover portrait display, missing portraits, character selection,
  command-grab whiff selection and missing block playback.
- macOS compiled-server checks and Windows host-side transport/PE/archive checks
  validate packaging and transport, not every native GUI interaction.
- **Native Windows WebView2 GUI acceptance remains unverified.** The Mac app is
  ad-hoc signed and not notarized; Windows is unsigned.
