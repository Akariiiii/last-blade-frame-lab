# Last Blade 2 Frame Lab v0.1.0-beta.1

Local frame viewer for saved Last Blade 2 recordings.

## New in this beta

- Added a newly drawn pixel-art Hibiki face icon for macOS Finder/Dock, Windows Explorer/title bar and the browser tab.
- Rebuilt both platforms with the same version and updated checksums.
- Added the MIT licence for viewer code/docs/demo, with preserved third-party notices in both app packages.

## Viewer features

- Recorded frame playback, stepping and collision overlays.
- Move timing, damage and independent reference comparisons.
- Separate held guard, switch guard and weapon rebound measurements.
- Contact markers and explicit unknown/upper-bound timing when collision snapshots are incomplete.
- Native macOS universal app and Windows x64 viewer.

## Downloads

- **macOS:** `LastBlade2-FrameLab-v0.1.0-beta.1-macOS-universal.zip` — Apple Silicon and Intel, macOS12+.
- **Windows:** `LastBlade2-FrameLab-v0.1.0-beta.1-Windows-x64.zip` — Windows10/11 x64; requires Microsoft Edge WebView2 Runtime. Extract the entire ZIP and keep the DLL/web folder beside the EXE.

The apps include a procedural demo. Real game recordings are a separate download: extract the pack and choose its folder containing manifest.json and extended/. No game ROM, BIOS, emulator, Node or Python is required for viewing saved recordings.

## Validation and requirements

The Mac app is ad-hoc signed and not notarized; the Windows executable is unsigned. Windows was cross-compiled and its shipping transport tested on the build host; actual Windows WebView2 playback and dialogs remain unverified. Recording coverage and transient hitbox evidence are incomplete; unknown values are kept visible.

Verify downloaded ZIPs against SHA256SUMS.txt.
