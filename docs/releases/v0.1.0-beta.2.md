# Last Blade 2 Frame Lab v0.1.0-beta.2

An updated offline frame viewer for saved Last Blade 2 recordings. This beta
ships the viewer source and macOS/Windows apps while frame-data research continues.

## Changes since beta.1

- A single **Hit / Block / Whiff** selector switches the selected recording,
  statistics and frame timeline together. Missing images remain explicit rather
  than borrowing a clip from another outcome.
- Multi-hit contact details and observed stun values accompany the main timing,
  damage, advantage and meter cards. Conditional values retain their source and
  target context.
- Held guard, released guard, switch guard, rebound and recovery research remain
  distinct. Available landing tests separate physical touchdown, observed input
  and admission of a new grounded attack.
- Distance and verified native ground-grab range follow playback and stepping.
  Move-property panels distinguish native dispatch rules, recorded outcomes and
  still-unmeasured physical cancel/tech windows.
- Larger, clearer text and less intrusive range labels improve readability.
- Data import retains optional research registries/CSVs and reference images;
  native app packages preserve the MIT and third-party notices.

## Data scope and remaining work

The local research snapshot used during this release preparation has **7,516
indexed image clips**. It is not a claim of complete move or Hit/Block/Whiff
coverage. Remaining work includes legal whiff setups, exact transient activity,
broader aerial/landing timing, physical cancel/tech/target-state windows, and
successful aerial-deflect follow-ups. Native conditional lookup results do not
prove a complete physical input window. Unknowns and timing bounds remain visible.
Wiki numbers are independent comparisons rather than substitutes for measurements.

The app ZIPs and public repository contain the procedural demo only. **Real
recordings stay local and are not included or uploaded with this release.**
Existing compatible packs can be opened with **Choose Data Folder**. ROMs, BIOS
and emulator binaries are not part of the viewer distribution.

## Downloads

- **macOS:** `LastBlade2-FrameLab-v0.1.0-beta.2-macOS-universal.zip` — Apple Silicon
  and Intel, macOS 12+. Extract and open **Last Blade 2 Frame Lab.app**.
- **Windows:** `LastBlade2-FrameLab-v0.1.0-beta.2-Windows-x64.zip` — Windows 10/11
  x64 with Microsoft Edge WebView2 Runtime. Extract the entire ZIP and keep the
  EXE, loader DLL and `web/` folder together.

No Node.js, Python or emulator is required to use either packaged viewer.
Use `SHA256SUMS.txt` to verify the downloaded ZIPs. `release-manifest.json` records
the release identity, asset hashes and release-note hash.

## Validation and platform limits

Source tests, TypeScript and production builds are checked. The packaged macOS
transport is tested directly. Windows is cross-compiled and structurally verified;
host-side transport checks do not establish native Windows WebView2 playback,
folder-selection dialogs or exports. **Native Windows GUI acceptance remains
unverified.** The Mac app is ad-hoc signed and not notarized; Windows is unsigned.
