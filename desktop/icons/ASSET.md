# Hibiki application icon

New pixel-style fan portrait of Hibiki Takane, generated for this project with the built-in imagegen tool. The master is `hibiki.png`; it is not copied from a game sprite or existing illustration. Character reference: Hibiki Takane from The Last Blade 2 (long dark hair, yellow ribbon and red kimono). No external image was used as an edit target.

`FrameLab.icns`, `FrameLab.ico` and `public/app-icon.png` are packaging conversions of the master. `npm run icons:build` uses nearest-neighbor resizing and retains transparency. Normal application builds use the prebuilt assets and do not require ImageMagick.

The application licence does not grant rights in SNK's depicted character, character design or trademarks. See the project's `NOTICE.md` for the source and asset licence boundary.

Generation prompt:

> Use case: stylized-concept. Asset type: final desktop application icon, one square icon only. Create an original, lovingly drawn pixel-art close-up portrait of Hibiki Takane from The Last Blade 2. She must be recognizable by long black hair tied back with her prominent yellow/gold ribbon, straight dark bangs, warm pale skin, calm focused dark eyes, and a small glimpse of her red kimono with ivory collar. Frame head and upper shoulders, slight three-quarter face, face large and centered for strong readability at 32px. Authentic late-1990s Neo Geo portrait pixel craft, restrained 20-30 color palette, clearly visible square pixel clusters, strong silhouette, crisp edges, no anti-aliasing, no blur or painterly gradients. Compose like an approximately 64x64 logical pixel drawing enlarged cleanly. Place the portrait inside a simple dark forest-green rounded-square app-icon tile, with subtle pixel-stepped edges and a quiet muted-gold border; outside the tile is genuinely transparent. Leave safe padding so hair and ribbon are not clipped. No sword, no scenery, no additional characters, no text, no letters, no logo, no watermark. Deliver just the finished standalone app icon, no sheet, no mockup, no alternative panels. This is a newly drawn fan icon, not a copy of an existing game sprite or illustration.
